# NallaNudi 📚🗣️

NallaNudi is an Android application developed to promote better communication, language learning, and smart educational interaction for students and teachers. The application provides a simple, modern, and user-friendly platform with clean UI and efficient performance.

---

# 🚀 Features

- 🔐 User Authentication (Login & Register)
- 📖 Language Learning Support
- 🗣️ Speech & Text Interaction
- 📱 Modern Android UI Design
- 🌐 Internet Connectivity Support
- ⚡ Fast & Lightweight Performance
- 🎯 Easy Navigation
- 📂 Organized Project Structure

---

# 🛠️ Technologies Used

- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Realtime Database / Firestore
- XML UI Design
- Material Design Components

# ⚙️ Installation Steps

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/NallaNudi.git
```

## 2️⃣ Open in Android Studio

- Launch Android Studio
- Click Open Project
- Select the NallaNudi folder

## 3️⃣ Sync Gradle

Wait for Gradle build and dependency sync.

## 4️⃣ Run the Application

Run using:

- Android Emulator
OR
- Physical Android Device
